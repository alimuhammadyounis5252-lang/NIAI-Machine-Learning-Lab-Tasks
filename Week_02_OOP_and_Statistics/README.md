## Directory Contents & Task Mapping

| Task # | File Name | Description |
|---|---|---|
| **Task 20** | `Task_20_functions_and_scope.py` | Functions, docstrings, positional/keyword/default arguments, `*args`, `**kwargs`, scope (`local`, `global`, `nonlocal`), lambda expressions, `map()`, and `filter()`. |
| **Task 26** | `Task_26_exception_handling.py` | Robust exception handling with `try`, `except`, `else`, `finally`, handling `ZeroDivisionError`, `ValueError`, `TypeError`, and `FileNotFoundError`. |
| **Task 27** | `Task_27_user_defined_exceptions.py` | Custom user-defined exception classes inheriting `Exception` (`InvalidInputRangeError`, `ModelNotFittedError`) with input validation. |
| **File I/O** | `Task_OOP_File_Handling.py` | File reading, writing, appending, and safe resource management using Python context managers (`with open(...)`). |
| **OOP 1** | `Task_OOP_01_Classes_and_Objects.py` | Classes and Objects, instance variables vs class variables, constructor `__init__`, destructor `__del__`, instance methods, `@classmethod`, and `@staticmethod`. |
| **OOP 2** | `Task_OOP_02_Inheritance_and_MRO.py` | Single, Multilevel, Hierarchical, and Multiple Inheritance, Method Resolution Order (MRO), and `super()` coordination. |
| **OOP 3** | `Task_OOP_03_Encapsulation_and_Access.py` | Access specifiers: Public, Protected (`_`), and Private (`__`), Name mangling, and getter/setter properties with `@property`. |
| **OOP 4** | `Task_OOP_04_Polymorphism_and_Dunder.py` | Dynamic polymorphism, method overriding, and operator overloading via dunder/magic methods (`__str__`, `__repr__`, `__len__`, `__add__`, `__eq__`). |
| **OOP 5** | `Task_OOP_05_Advanced_OOP_and_Design.py` | Abstract Base Classes (`abc.ABC`, `@abstractmethod`), Empty Class, `@dataclass`, Inner/nested classes, and Composition vs Aggregation. |
| **Task 49** | `Task_49_mean_median_mode.py` | Measures of Central Tendency (Mean, Median, Mode) implemented via manual calculations, Python `statistics`, `scipy.stats`, and `numpy`. |
| **Task 50** | `Task_50_dispersion_and_position.py` | Measures of Dispersion & Position: Variance ($\sigma^2$), Standard Deviation ($\sigma$), Range, IQR, Skewness, Kurtosis, Z-Score, Percentiles, and data type taxonomy. |
| **Runner** | `run_all_week2.py` | Automated test runner verifying all Week 2 Python scripts. |
