## 🚀 Quick Execution Guide

### 1. Prerequisites
Install all required libraries using pip:
```bash
pip install numpy pandas scipy matplotlib seaborn scikit-learn
```

### 2. Running Individual Modules
To test any week's full test suite in one command:

```bash
# Week 1:
python Week_01_Python_Fundamentals_and_Linux/run_all_week1.py

# Week 2:
python Week_02_OOP_and_Statistics/run_all_week2.py

# Week 3:
python Week_03_NumPy_and_Probability/run_all_week3.py

# Week 4:
python Week_04_Pandas_Seaborn_Linear_Regression/run_all_week4.py

# Week 5:
python Week_05_Machine_Learning_Logistic_Regression/run_all_week5.py
```
